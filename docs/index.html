步驟 01

這是什麼與支援網站

本工具是一套輕量的 Chrome 擴充功能（Manifest V3）。當您瀏覽支援網站的影片頁面時，程式會自動從網址擷取番號（例如 /videos/mikr-112/ → MIKR-112），前往 subtitlecat.com 檢索繁體或簡體中文字幕，並直接繪製在播放畫面下方。

jable.tv (含 *.jable.tv) 已實測支援

已完整實測。程式適配 Jable 所採用的 Plyr 播放器，可自動精準鎖定主影片時長，並智慧排除預覽縮圖影片與插播廣告。

missav.ws / missav.ai 作者實測可用

作者在 MissAV 上實測字幕可正常顯示。若在某部影片上字幕未正常疊加，歡迎依文末指示提供日誌回報。

免去手動搜尋與外掛檔案：不用再另開分頁尋找字幕檔案，擴充功能會在背景完成檢索、下載與格式轉換，直接在網頁畫面呈現。

步驟 02

安裝與更新擴充功能

本工具目前以開發原始碼形式發布，未上架至 Chrome 線上應用程式商店。請使用 Chrome 內建的「載入未封裝項目」功能進行安裝。

  1. 1
    在 Chrome 網址列輸入 chrome://extensions 並按下 Enter，開啟擴充功能管理中心。
  2. 2
    在頁面右上角，將「開發人員模式」（Developer mode）開關切換為開啟。
  3. 3
    點擊左上角出現的「載入未封裝項目」（Load unpacked）按鈕。
  4. 4
    在檔案瀏覽視窗中，選取本專案的根目錄 subtitlecat-ext 資料夾即完成安裝。
更新程式時的步驟：
當擴充功能代碼有變更時，請至 chrome://extensions 找到本擴充功能，點擊卡片上的「重新載入」（旋轉箭頭圖示），並在影片分頁按 F5 重新整理頁面。

步驟 03

使用方式與快捷鍵操作

開啟符合番號規則的影片網址（如 https://jable.tv/videos/mikr-112/）後，畫面左下角將常駐黑色狀態小徽章，格式為 [番號] 狀態。

  • A
    切換字幕語系：
    直接點擊左下角徽章或按下鍵盤鍵 C，即可快速循環切換語系。
  • B
    輸入文字時防誤觸：
    當游標正在文字輸入框（<input> 或 <textarea>）內鍵入內容時，按 C 鍵不會觸發字幕切換，絕不干擾打字。
  • C
    全螢幕觀看支援：
    當播放器切換至全螢幕時，徽章會自動同步移入全螢幕容器中。全螢幕下建議優先使用 C 鍵切換。
  • D
    調整字幕樣式：
    點瀏覽器工具列上的擴充功能圖示（若沒看到，先從拼圖圖示釘選），可調整字體顏色與透明度、大小、字形、邊緣、背景，以及字幕離畫面底部的距離，上方有預覽。開著影片頁調整時，影片上的字幕會同步變化，設定會自動儲存；按「重設」可回到預設值。
主影片掛載提示：
當字幕成功掛載至主要影片時，徽章文字後方會自動追加解析度與時長資訊（例如 · 影片 930×523 時長144分），代表已鎖定正確的主片。

步驟 04

注意事項與疑難排解

擴充功能設計強調輕量、安全與對來源站點友善，以下為字幕來源特性與快取機制說明：

字幕來源與格式

字幕源自 subtitlecat.com 的機器翻譯，品質因片而異。每則字幕通常包含兩行（中文譯文與原文英文），此為來源 SRT 檔案本身的原始格式。

請求節流與本機快取

對 subtitlecat.com 請求至少間隔 1 秒。查獲的字幕會儲存於瀏覽器本機（chrome.storage.local）；若查無字幕亦會快取 1 小時，避免頻繁重複請求。

個人隱私承諾

完全不會將任何觀看紀錄、番號或個人資訊傳送至 subtitlecat.com 以外之第三方伺服器，無需註冊帳號、無任何分析追蹤代碼。

資料庫收錄限制

僅當 subtitlecat 資料庫有收錄該番號時才會有字幕；若來源庫未收錄，徽章將明確提示「subtitlecat 沒有中文字幕」。

看不到字幕時的排查步驟：
1. 按 F12 開啟瀏覽器開發者工具（DevTools），切換至 Console（主控台）分頁。
2. 在上方篩選欄位（Filter）輸入 [subtitlecat-ext]。
3. 將篩選出的除錯日誌，連同左下角徽章上的狀態文字一併提供給開發者。
